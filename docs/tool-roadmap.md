## หลักฐาน Google Trends ประเทศไทย

ตรวจวันที่ 3 สิงหาคม 2026 ช่วง 12 เดือนย้อนหลัง ประเภท Web Search:

- คำอังกฤษ: `pdf to jpg` เฉลี่ย 76, `merge pdf` 15, `compress pdf` 6 และ `split pdf` 5
- คำไทย: `รวม pdf` เฉลี่ย 81, `แปลง pdf เป็น jpg` 41, `แยก pdf` 14 และ `ลดขนาด pdf` 4
- กลุ่ม `vat calculator`, `json to csv` และ `csv cleaner` มีข้อมูลต่ำมากเมื่อเทียบในชุดเดียวกัน จึงเลื่อน Batch สำนักงานออกไป
- ไม่เปิด PDF Compressor แม้มีความสนใจ เพราะยังลดขนาดจริงอย่างสม่ำเสมอโดยไม่ลดคุณภาพหรือทำเอกสารเสียไม่ได้
- รอบเครื่องมือไทยทั่วไป: `วงล้อสุ่ม` เฉลี่ย 59 และ `พ.ศ. ค.ศ.` 35 สูงกว่า `คำนวณเกรด` 2, `จับเวลาออนไลน์` 1 และ `คำนวณ vat` 0 ในชุดเปรียบเทียบเดียวกัน
- รอบทบทวนเครื่องมือภาพเทียบกับ Anchor ที่ส่งมอบแล้ว: `ลบพื้นหลัง` 60, `วงล้อสุ่ม` 59, `แปลงรูปเป็นข้อความ` 1, `ทำรูปติดบัตร` 1 และ `ครอปรูป` 1 ในชุดเดียวกัน
- รอบเครื่องคำนวณงานและการเงิน: `คำนวณภาษี` 56, `คำนวณดอกเบี้ย` 24, `คำนวณเงินเดือน` 24, `คำนวณ vat` 3 และ `คำนวณโอที` 1 ในชุดเดียวกัน
- รอบงานเอกสารและการตรวจข้อมูลเทียบกับ Anchor `วงล้อสุ่ม` 59: `เช็คเลขบัตรประชาชน` 8, `เซ็น pdf` 3, `ตัวเลขเป็นตัวอักษร` 1 และ `ลายเซ็นออนไลน์` 0
- รอบเงินเดือนและสลิป: `สลิปเงินเดือน` 60, `คำนวณเงินเดือน` 5, `คำนวณประกันสังคม` 3, `คำนวณเงินเดือนสุทธิ` 0 และ `คำนวณโอที` 0 ในชุดเดียวกัน
- ตรวจ search intent เพิ่ม: `สลิปเงินเดือนออนไลน์` 1 แต่ `สร้างสลิปเงินเดือน`, `โปรแกรมสลิปเงินเดือน` และ `ตัวอย่างสลิปเงินเดือน` 0 จึงเลือกทำเครื่องมือตรวจยอด ไม่สร้างเอกสารที่อาจถูกนำไปใช้ผิดวัตถุประสงค์
- เทียบงานสำนักงานโดยใช้ `คำนวณเงินเดือน` เป็น Anchor: `คำนวณเงินเดือน` 63, `แปลง csv` 2, `คำนวณวันทำงาน` 2, `ลบข้อมูลซ้ำ excel` 1 และ `แปลงเลขเป็นตัวหนังสือ` 0
- รอบสิทธิและรายได้: `คำนวณเงินเดือน` 63, `คำนวณบำนาญ` 31, `คำนวณเงินเดือนข้าราชการ` 5, `คำนวณเงินชราภาพ` 3 และ `คำนวณค่าชดเชย` 1
- แยก intent บำนาญเพิ่ม: `คำนวณบำนาญ` เฉลี่ย 32, `คำนวณบำนาญประกันสังคม` 5 และ `คำนวณบำนาญข้าราชการ` 0 ในชุดเดียวกัน จึงส่งมอบเครื่องมือ ม.33/ม.39 ที่ใช้สูตร FAE ปัจจุบัน โดยยังไม่คำนวณ CARE ซึ่ง ครม. เห็นชอบเพียงร่างเมื่อ 14 กรกฎาคม 2569 และกำหนดให้มีผลหลังประกาศราชกิจจานุเบกษาแล้ว 180 วัน
- รอบ Batch 11: `เช็คเลขบัตรประชาชน` เฉลี่ย 25 สูงกว่า `จัดหน้า pdf` 4, `คำนวณ vat` 1, `ลบข้อมูลซ้ำ` 0 และ `คำนวณวันทำงาน` 0 ในชุดเดียวกัน
- แยก intent เลขบัตรเพิ่ม: `เลขบัตรประชาชน` 44, `เช็คบัตรประชาชน` 23, `เช็คเลขบัตรประชาชน` 13, `ตรวจเลขบัตรประชาชน` 4 และ `ตรวจสอบเลขบัตรประชาชน` 3 จึงส่งมอบเฉพาะตัวตรวจ checksum ฝั่ง Browser ไม่เชื่อมฐานรัฐ ไม่สร้างเลข และไม่อ้างว่าเป็นการยืนยันตัวตน
- ค่า Google Trends เป็นดัชนีความสนใจสัมพัทธ์ในชุดคำและช่วงเวลาที่เลือก ไม่ใช่จำนวนค้นหาจริง จึงใช้คัดลำดับร่วมกับประโยชน์ ความเสี่ยง และความเป็นไปได้ทางเทคนิค

## ลำดับส่งมอบที่แนะนำ

1. Batch 3 — ภาพสำหรับร้านค้า: PNG/WebP เป็น JPG, บีบอัดและย่อขนาด — ส่งมอบแล้ว
2. Batch 4 — Popular Utilities: Color Picker/Contrast, Password และ Random Number — ส่งมอบแล้ว
3. Batch 5 — PDF Utilities: PDF to JPG, Merge PDF, Split PDF — ส่งมอบแล้ว
4. Batch 6 — เครื่องมือไทยที่มี demand สูง: Random Wheel และ Buddhist Year Converter — ส่งมอบแล้ว
5. Batch 7 — AI Background Remover แบบ client-only และ lazy model — ส่งมอบแล้ว
6. Batch 8 — Thai Income Tax Calculator พร้อมสูตรขั้นบันไดและแหล่งอ้างอิงราชการ — ส่งมอบแล้ว
7. Batch 9 — Salary & Payslip Calculator สำหรับตรวจยอดโดยไม่สร้างเอกสารรับรอง — ส่งมอบแล้ว
8. Batch 10 — Social Security Pension Calculator สูตร FAE ปัจจุบัน พร้อมตรวจเงื่อนไขและสถานะร่าง CARE — ส่งมอบแล้ว
9. Batch 11 — Thai ID Checksum Validator แบบ privacy-first ไม่เชื่อมฐานรัฐ — ส่งมอบแล้ว
10. Batch 12 — วิจัย PDF Organizer, CSV Cleaner, VAT, ใบเสนอราคา และ Sign PDF เพิ่มก่อนเลือกงานถัดไป

ทุก Batch ควรมี unit test ของสูตรหรือ parser, E2E อย่างน้อยหนึ่งเส้นทาง, ตรวจ keyboard/mobile และวัด Core Web Vitals ก่อนเปิด AdSense ใน production
